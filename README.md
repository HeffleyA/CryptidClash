Cryptid Clash in its current iteration is a melee fighting game for 2-4 players.
Each player plays as Bigfoot and can move, punch and teleport to fight each other.

Cryptid Clash plays as a king of the hill game and the first player to get 15 points from the "point" wins the game.

To install and run Cryptid Clash, simply clone the repository, open the cloned project in Unreal Engine 5.8 or higher, set your preferred player count, and press play!
